## CHECKLIST POR ARTIGO

Ao criar cada novo artigo, seguir:

### 1. Conteúdo
- [ ] Título atraente (60 caracteres max)
- [ ] Subtítulo impactante
- [ ] Introdução com problema + solução
- [ ] Mínimo 4 seções principais (## Heading 2)
- [ ] Mínimo 1.500 palavras
- [ ] Legítimo, informativo, empático

### 2. Estrutura
- [ ] Imagem de destaque
- [ ] Tags relevantes (3-5)
- [ ] Keywords SEO (5-10)
- [ ] Read time estimado
- [ ] Data de publicação

### 3. Linking
- [ ] 2-3 artigos relacionados
- [ ] CTA específico do artigo
- [ ] Links internos no corpo do texto
- [ ] Link de voltar ao blog

### 4. SEO
- [ ] Meta description (155 caracteres)
- [ ] OpenGraph tags
- [ ] Twitter Card
- [ ] H1, H2, H3 bem estruturados

### 5. Conversão
- [ ] CTA adequado para estágio do funil
- [ ] WhatsApp link personalizado
- [ ] Oferta clara (análise grátis, consulta, etc)

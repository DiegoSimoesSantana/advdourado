# Origem da unificação

A base técnica principal foi promovida a partir do projeto de consumidor por ser a estrutura mais moderna e estável para Next.js.

## Projetos analisados
- consumidor: base mais atual, com blog e estrutura de conteúdo forte.
- trabalhista: melhor material de captação e ferramentas especializadas.
- educacional: bom conteúdo institucional e materiais informativos.

## Ajustes já feitos
- Unificação das três frentes em uma única home institucional.
- Centralização de conteúdo e contatos em `lib/site-config.ts`.
- Adequação de linguagem para tom institucional e informativo.
- Ajustes de build do Next.js para compilação estável.

## Observações técnicas
- A instalação mais estável nesta base foi com `npm install --legacy-peer-deps`.
- O build de produção já foi validado com sucesso.
